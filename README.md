# Événements autour d'Alboussière

Calendrier public des événements sélectionnés autour d'Alboussière (Ardèche).

## Calendrier Apple

Une fois GitHub Pages activé, le flux sera disponible à :

https://Cufflink9705.github.io/evenements-alboussiere/evenements.ics

Il peut être ajouté à Apple Calendrier comme calendrier par abonnement.

### Ajouter un événement individuel sur Mac

Sur la page Agenda, le bouton **Ajouter à mon calendrier** télécharge un fichier `.ics` portant le nom de l’événement. Sur macOS, ouvre ce fichier téléchargé (double-clic) : l’app Calendrier affiche alors son interface d’ajout/import, à confirmer par l’utilisateur. Le site ne peut pas forcer le lancement direct de l’application native depuis tous les navigateurs, mais le fichier est au format iCalendar standard et reste compatible avec Calendrier sur Mac, iPhone et les autres agendas prenant en charge `.ics`.

## Périmètre

- Rayon principal : 75 km autour d'Alboussière
- Extension 75–100 km : événements intéressants
- Extension 100–150 km : uniquement événements exceptionnels
- Recherche : VTT/VTTAE/enduro, randonnées, trails, nature, culture, fêtes, brocantes importantes, patrimoine, famille, mobilité, conférences et activités gratuites/peu coûteuses
- Exclusions : vélo de route, cyclotourisme, Gravel, événements commerciaux ordinaires, doublons et événements non datés/non publiés

Le contenu est prévu pour être actualisé par la veille quotidienne à 06:00 (Europe/Paris). Le calendrier public `evenements-web.ics` contient toutes les catégories retenues ; `evenements.ics` ne contient que les événements VTT/VTTAE/enduro/endurando/XC/DH. Les événements passés doivent être retirés à chaque actualisation.

Les annonces Rammstein en France et les dates du Buffet du Canon Français sont suivies dans la veille Actualité quotidienne, pas dans la veille événementielle locale.
